**Parte 2:** **Projeto de uma base móvel para o braço robótico **usando Ahmes:

**1. Objetivo do Projeto**

Criar um sistema para controle de uma base robótica utilizando a linguagem Ahmes. O sistema permitirá o controle da direção e velocidade da base robótica, podendo ser utilizado em automação ou robótica.

**2. Funcionamento**

* O sistema deve permitir **controle do sentido** dos motores das rodas da base robótica.
* O microcontrolador (simulador) receberá os sinais nos pinos de entrada e enviará os sinais de controle (acionamento dos motores) na saída para alternar a ativação dos motores. A base móvel, deverá ser capas de ir para frente e para trás, girar 360º e virar para a direita e esquerda.
 

Essa nota será exclusivamente avaliada pelo Professor.
